# JetBrains Mono source fonts

Unmodified upstream JetBrains Mono v2.304 inputs for offline atlas generation.
Regular and Medium are retained for the planned weight comparison. The runtime
renderer has not yet been implemented and does not load these files.

Source: <https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/ttf>

The fonts are licensed under SIL Open Font License 1.1; see `OFL.txt`.
